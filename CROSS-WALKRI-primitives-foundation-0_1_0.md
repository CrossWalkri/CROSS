# Superseded: see GRAIN

This document, formerly the CROSS+WALKRI Primitives Foundation, was reworked into GRAIN, the Grant Representation And Interchange Notation, in August 2026. It is retained only as a redirect.

The canonical source is now GRAIN-notation-0_1_0.md, in the repository CrossWalkri/GRAIN. GRAIN is the descriptive grant notation: the grammar a grant program decomposes into and recomposes from, independently adoptable and composable with CROSS.

What this document once carried and where it now lives: the grant primitives are in GRAIN; the criterion specification elements, the data-quality standards, external standard identifier types, and access models are WALKRI's own and live in WALKRI; the Layer 1 methodological commitments (bidirectional precision, transclusion, Frame Language inheritance, format agnosticism, independent verifiability) live in the Precision-First Design Standard and Frame Language.

Do not edit or cite this file. Use GRAIN.
